# 🤖 my-agent: 개인 비서 에이전트

OpenAI API의 **function calling**으로 만든 터미널 개인 비서입니다.
대화하면 모델이 필요한 도구(메모, 할 일, 계산, 날씨, 시간)를 알아서 골라 씁니다.

## 실행

**창(GUI) 버전**: `개인비서.bat` 더블클릭 (또는 `uv run app.py`)
- 처음 실행 때 API 키가 없으면 입력창이 뜨고, 입력한 키는 `.env`에 저장됩니다.
- 오른쪽 위 `새 대화`로 기록 초기화, `API 키`로 키 변경.

**터미널 버전**: `uv run main.py`

## Notion 연결 (공부 비서)

부트캠프 정리 DB를 비서가 읽고 쓰게 하려면 **딱 한 번** 아래 설정이 필요함.

1. https://www.notion.so/profile/integrations 접속 → **새 API 통합** → 이름 `개인비서`, 워크스페이스 선택 → 저장
2. 생성된 **내부 통합 시크릿**(`ntn_...`) 복사
3. Notion에서 **SKN AI 35기 부트캠프 정리용** DB 페이지 열기 → 오른쪽 위 `•••` → **연결** → `개인비서` 추가
   (이걸 안 하면 404 오류가 남. 통합은 연결된 페이지만 볼 수 있음)
4. 비서 창 오른쪽 위 **Notion** 버튼 → 토큰 붙여넣기 (또는 `.env`에 `NOTION_TOKEN=` 추가)

`NOTION_DATA_SOURCE_ID`는 이미 `.env`에 들어가 있음.

이렇게 써 보기:
- `최근에 뭐 배웠지?` / `복습 안 한 노트 뭐 있어?`
- `군집화 정리한 거 찾아서 설명해줘`
- `45일차로 복습 퀴즈 내줘`
- `오늘 배운 LangGraph 내용 정리해서 노션에 올려줘` (저장 전에 미리보기로 확인함)

**PDF로 노트 만들기**
- 한 개: 📎로 PDF 선택 → `이거 80일차로 정리해줘` → 미리보기 확인 → `저장해`
- 여러 개(밀린 날 채우기): 📎로 PDF 여러 개 선택 → **📝 노트로 정리** → PDF마다 정리 카드가 생김
  - 제목(80일차, 81일차…)과 날짜(다음 평일)가 자동으로 채워짐. 파일 이름순 = 날짜순으로 가정
  - 정리본은 카드에서 직접 고칠 수 있고, **Notion에 저장** 버튼으로 하나씩 저장
  - 하루치 강의가 PDF 여러 개면 **하루치로 합치기** 체크 → 카드 하나로 합쳐짐
- DB의 `날짜` 속성에 강의 날짜가 들어감 (`작성일시`는 Notion이 자동으로 찍어서 못 바꿈)
(새 PDF를 첨부하면 이전 PDF 본문은 대화 기록에서 빠져서 비용이 쌓이지 않음.
 이미지/스캔 PDF는 글자를 못 읽음 → 첨부할 때 ⚠️ 경고가 뜸)

처음 실행 때 노트 전체를 내려받느라 약 10분 걸림 (백그라운드라 그동안 대화 가능, 창 아래 진행률 표시).
Notion이 요청 속도를 제한해서 더 빠르게는 안 됨. 이후엔 바뀐 노트만 받아서 1초 이내 (`data/notion_cache.json`).

## exe 만들기

`build.bat` 더블클릭 → `dist\PersonalAssistant.exe` 생성 (약 21MB, 파이썬 설치 없이 실행 가능)

- exe는 아무 폴더로 옮겨도 됩니다. `.env`(API 키)와 `data\`(메모·할 일)는 **exe와 같은 폴더**에 생깁니다.
- 처음 실행 시 키 입력창이 뜹니다. 기존 `.env`를 exe 옆에 복사해 둬도 됩니다.
- 코드를 고친 뒤에는 `build.bat`을 다시 실행해야 exe에 반영됩니다.
- 첫 실행은 압축을 푸느라 몇 초 걸리고, 백신이 서명 없는 exe를 의심할 수 있습니다 (직접 만든 파일이면 허용).

예시:
```
나 > 내일까지 보고서 제출 할 일에 추가해줘
  🔧 get_current_time({"timezone": "Asia/Seoul"})
  🔧 add_todo({"task": "보고서 제출", "due": "2026-11-15"})
비서 > 할 일에 추가했어요! 마감은 내일(11/15)입니다.
```

## 파일 구조

| 파일 | 역할 |
|---|---|
| `app.py` | 창(GUI) 버전 - CustomTkinter 채팅 화면 |
| `main.py` | 터미널 버전 |
| `agent.py` | 에이전트 루프(`run_turn`), 시스템 프롬프트, 모델 설정 |
| `notion_tools.py` | Notion 공부 노트 검색·읽기·저장·복습 체크 (로컬 캐시 검색) |
| `curriculum.py` | 부트캠프 커리큘럼 1~120일차(날짜·과목) + 프로젝트 요약. 노트 날짜·과목 자동 입력에 씀 |
| `attachments.py` | PDF → 텍스트 추출, 이전 PDF 본문 정리 |
| `note_cards.py` | PDF 정리 카드 (제목·날짜·정리본 편집·저장) |
| `toolkit.py` | `@tool` 데코레이터 (함수 → 도구 스키마) |
| `paths.py` | `.env`·`data/` 위치 계산 (exe일 때는 exe 옆) |
| `개인비서.bat` | 더블클릭 실행용 (파이썬 버전) |
| `build.bat` | exe 빌드 |
| `tools.py` | 에이전트가 쓰는 도구들 (`@tool` 함수) + 스키마 자동 생성 |
| `data/` | 메모·할 일 저장 위치 (첫 실행 시 생성, git 제외) |
| `.env` | API 키 (git 제외) |

## 동작 원리

```
사용자 입력 → 모델에게 (대화 기록 + 도구 목록) 전송
   ↓
모델: "add_todo 도구를 이 인자로 불러줘"  (tool_calls)
   ↓
run_turn()이 tools.py 함수 실행 → 결과를 role="tool" 메시지로 다시 전달
   ↓  (도구가 더 필요하면 반복, 최대 15번)
모델: 도구 호출 없이 최종 답변
```

## 도구 추가하는 법

`tools.py`에 함수를 하나 만들고 `ALL_TOOLS`에 넣으면 끝입니다.
docstring이 그대로 모델에게 가는 설명서이므로 **언제 쓰는 도구인지** 분명히 적어 주세요.
인자 타입은 `str`, `int`, `float`, `bool`을 지원합니다.

```python
@tool
def roll_dice(sides: int = 6) -> str:
    """주사위를 굴립니다. 사용자가 무작위 선택을 원할 때 쓰세요.

    Args:
        sides: 주사위 면 수.
    """
    import random
    return str(random.randint(1, sides))
```

## 설정

- 모델 변경: `.env`에 `AGENT_MODEL=gpt-5.5` (기본값 `gpt-5.4-mini`는 저렴하고 빠름)
- 비서 성격/규칙 변경: `agent.py`의 `SYSTEM_PROMPT`
