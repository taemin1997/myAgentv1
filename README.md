# 🤖 my-agent: 개인 공부 비서 에이전트

OpenAI API의 **function calling**으로 만든 데스크톱 개인 비서.
부트캠프(SKN AI 35기) 공부 기록을 Notion DB에 쌓고, 찾고, 복습하고, 매일 갱신하는 일을 대화로 처리함.

- 💬 대화로 Notion 노트 검색·설명·복습 퀴즈
- 📎 PDF·Word·PPT·HTML·이미지를 끌어다 놓으면 그날 노트로 정리해서 Notion에 저장
- 🗂️ 정리 방식(템플릿)을 파일로 저장 → Notion 탭(일차 노트 / 회고 / 프로젝트 / 면접)에 맞는 형식으로 매일 새 페이지
- 🚀 최종 프로젝트 페이지를 그날 자료로 섹션별 갱신 (이때만 상위 모델 사용)
- 📝 생활 도구: 메모, 할 일, 계산, 날씨, 시간

## 실행

| 방법 | 설명 |
|---|---|
| `dist\PersonalAssistant.exe` | 빌드한 exe. 파이썬 없이 실행 (`scripts\build.bat`로 생성) |
| `scripts\개인비서.bat` 또는 `uv run app.py` | 파이썬(.venv)으로 바로 실행. 코드 고친 걸 빌드 없이 확인할 때 (`--ctk`면 예전 화면) |
| `uv run main.py` | 터미널 버전 |

- 처음 실행 때 API 키가 없으면 입력창이 뜨고, 입력한 키는 `.env`에 저장됨
- 오른쪽 위 `새 대화`로 기록 초기화, `Notion`으로 토큰 입력, `API 키`로 키 변경
- 답은 생성되는 대로 말풍선에 흘러나옴 (스트리밍, 쓰는 중엔 끝에 ▌ 표시)

## Notion 연결

부트캠프 정리 DB를 비서가 읽고 쓰게 하려면 **딱 한 번** 아래 설정이 필요함.

1. https://www.notion.so/profile/integrations → **새 API 통합** → 워크스페이스 선택 → 저장
2. 생성된 **내부 통합 시크릿**(`ntn_...`) 복사
3. Notion에서 **SKN AI 35기 부트캠프 정리용** DB 페이지 → `•••` → **연결** → 만든 통합 추가
   (안 하면 404 오류. 통합은 연결된 페이지만 볼 수 있음)
4. 비서 창 **Notion** 버튼 → 토큰 붙여넣기 (또는 `.env`에 `NOTION_TOKEN=`)

처음 실행 때 노트 전체를 내려받느라 약 10분 걸림 (백그라운드라 그동안 대화 가능, 창 아래 진행률 표시).
Notion이 초당 요청 수를 제한해서 더 빠르게는 안 됨. 이후엔 바뀐 노트만 받아서 금방 끝남 (`data/notion_cache.json`).

### DB 속성 (앱이 자동으로 채움)

| 속성 | 내용 |
|---|---|
| `강의명` | 제목. 일차 노트는 `N일차`, 회고는 `N주차 회고` |
| `날짜` | 강의 날짜. `N일차`면 커리큘럼에서 자동 (`작성일시`는 Notion이 찍어서 못 바꿈) |
| `과목` | `N일차`면 커리큘럼에서 자동 (예: 딥러닝), 프로젝트 페이지는 `단위/최종 프로젝트` |
| `분류` | DB 탭: 일차 노트 / 회고 / 프로젝트 / 면접 / 기타 |
| `유형` | 강의 / 실습 |

## 파일 첨부

📎 버튼(여러 개 선택) 또는 창에 **끌어다 놓기** (여러 개·폴더째 가능)

| 종류 | 형식 | 처리 |
|---|---|---|
| 문서 | PDF, Word(.docx), PowerPoint(.pptx), HTML, .txt .md .csv .json .py … | 글자만 뽑아서 보냄 (표·제목 구조 유지, cp949 텍스트도 읽음) |
| 이미지 | .png .jpg .webp .gif | 그림 그대로 보냄 → 그림 속 글자·도형도 읽음 |
| 못 읽음 | .hwp, 옛날 .doc/.ppt, 엑셀 | PDF로 저장해서 첨부. 스캔 PDF는 페이지를 캡처해 이미지로 |

다음 첨부 때 예전 첨부 본문·이미지는 대화 기록에서 빠져서 비용이 쌓이지 않음.

## 정리 방식(템플릿)

첨부창 드롭다운 = Notion 탭. 고르고 **📝 노트로 정리** → 파일마다 정리 카드가 생기고, 확인·수정 후 저장.

| 드롭다운 | 템플릿 | 만드는 페이지 |
|---|---|---|
| 📅 일차 노트 · 강의 | `강의노트` | 강의 자료 → `N일차` (무엇 → 왜 → 어떻게, 코드, 한 줄 복습) |
| 📅 일차 노트 · 회의록 | `회의록` | 회의록·기획 자료 → `N일차` (오늘 한 일, 논의, 결정 vs 미확정 표, 다음 작업 체크박스, 면접 연결) |
| 📝 회고 | `주간회고` | 한 주 자료 → `N주차 회고` (느낀 점은 '(직접 작성)'으로 비워 둠) |
| 🚀 프로젝트 | `프로젝트` | 프로젝트 소개 페이지 (미니프로젝트 1~4 형식). 자료 없으면 빈 틀 |
| 🎯 면접 | `면접` | 면접 예상 질문·답변. 기존 `면접 예상` 페이지에 이어 쓰기도 됨 |

- **하루치로 합치기** 체크 → 여러 파일을 카드 하나로
- 채팅으로 해도 됨: `이 회의록 89일차로 정리해줘` → 알맞은 템플릿을 불러서 그 형식으로 정리
- 형식 바꾸기: `앞으로 회의록에 '결정 사항' 칸 맨 위에 넣어줘, 기억해` → 템플릿 파일이 고쳐짐
- 직접 고쳐도 됨: `prompts/회의록.md` (exe는 `dist\prompts\`). 맨 위 `설명/분류/유형/과목/제목` 줄, `---` 아래가 지시문
- 대화 전체가 아니라 **정리 방식만** 저장 → 평소 요청 토큰은 거의 안 늘어남 (템플릿은 정리할 때만 읽음)

## 최종 프로젝트 매일 갱신

📎로 그날 자료(회의록, 기획서, 아키텍처 그림 …) 첨부 → `오늘 자료로 최종 갱신해줘`

1. 그날 `N일차` 노트를 회의록 형식으로 정리 → 보여주고 확인 → 저장
2. `최종 프로젝트 — Compare Agent 2.1` 페이지를 읽고 바뀐 섹션만 고름
   - **교체**: 개요, 팀 구성, 기술 스택, 시스템 구조, 결과
   - **이어 쓰기**: 내가 한 일, 트러블슈팅, 배운 점, 면접 예상 질문, 진행 기록(날짜 · 한 줄 · 노트 링크)
3. 팀 저장소에서 **그날 내 커밋**을 읽어서 '내가 한 일'에 커밋 링크와 함께 추가 (`get_my_commits`)
4. 바뀔 섹션 목록을 보여주고 `응` 하면 반영 (`update_page_section` 도구, 페이지 전체를 다시 만들지 않음)
5. 잘못 바뀌었으면 `방금 갱신 되돌려줘` → 직전 질문에서 한 수정을 통째로 되돌림 (`undo_last_update`)

작업 순서는 `prompts/최종갱신.md`. 프로젝트 페이지의 `## 1. 개요` 같은 섹션 제목은 앱이 섹션을 찾는 기준이라 바꾸지 말 것.

### 내 커밋 가져오기 (`tools/github.py`)

- 팀이 개인 브랜치에서 작업하니까 **모든 브랜치**에서 내 커밋을 찾고, 같은 커밋은 하나로 합침. 머지 커밋은 제외
- 커밋 메시지 + 바뀐 파일(+추가/-삭제)을 근거로 요약. 커밋에 없는 내용은 안 씀
- 채팅으로도 됨: `11/16 내 커밋 보여줘`, `이번 주 내가 커밋한 거 정리해줘`
- 기본 저장소·아이디는 `.env`의 `GITHUB_REPO`, `GITHUB_AUTHOR`로 바꿀 수 있음
- 토큰 없이 시간당 60번 요청 가능 (하루 갱신에 10~20번). 모자라면 `GITHUB_TOKEN`(읽기 전용) 추가

### 되돌리기 (`undo_last_update`)

- 앱이 Notion을 고칠 때마다 지운 블록(토글 안·표 행까지)과 새로 넣은 블록을 `data/update_history.json`에 기록
- 한 질문에서 한 수정은 한 묶음 → 되돌리기 한 번에 같이 되돌아감. 한 번 더 하면 그 전 묶음
  - 교체한 섹션 → 원래 내용 복구 / 이어 쓴 줄 → 삭제 / 새로 만든 섹션 → 삭제 / 새로 만든 페이지 → 휴지통
- 최근 40건까지 보관. 업로드 파일(이미지 등) 블록은 주소가 만료돼서 복구 못 함 (자리 표시만 남김)

## 모델

| 설정 | 기본값 | 쓰는 곳 |
|---|---|---|
| `AGENT_MODEL` | `gpt-5.4-mini` | 평소 대화·검색·정리·퀴즈 |
| `AGENT_MODEL_HEAVY` | `gpt-5.4` | 최종 프로젝트 갱신만 (긴 페이지 읽고 기존 내용 살려서 합쳐야 해서) |

- 모델이 `최종갱신` 템플릿을 부르거나 섹션을 고치면 다음 단계부터 상위 모델로 전환 (대화창에 ⚡ 표시)
- 계획 → `응 반영해` 턴까지 유지되고, 반영을 마치면 다시 기본 모델로 돌아감
- 바꾸려면 `.env`(exe는 `dist\.env`)에 한 줄 추가하고 앱만 다시 켜면 됨 (빌드 다시 안 해도 됨)

## 비용

- 창 위쪽에 **이번 대화 · 오늘** 비용이 보임. 마우스를 올리면 토큰 수·모델별·이번 달 합계
- 모델 응답의 토큰 사용량 × `core/usage.py` 가격표로 계산한 **추정치** (실제 청구는 OpenAI 대시보드).
  가격이 바뀌면 `.env`에 `PRICE_GPT_5_4_MINI=0.75,0.075,4.5`처럼 (입력, 캐시 입력, 출력 $/100만 토큰)
- 날짜별 기록은 `data/usage.json`
- 대화가 길어지면(추정 24,000토큰, `SUMMARY_TRIGGER_TOKENS`) 최근 질문 4개만 원문으로 두고 그 앞은 싼 모델로 요약해서 줄임
  (매 질문마다 기록 전체를 다시 보내서, 기록이 길수록 질문 하나가 비싸지기 때문). 최종 프로젝트 갱신 중엔 맥락이 중요해서 안 줄임

## exe 만들기

`scripts\build.bat` 더블클릭 → `dist\PersonalAssistant.exe` 생성 (파이썬 설치 없이 실행 가능)

- `.env`·`data\`·`prompts\`는 **exe와 같은 폴더**에 생김. `build.bat`이 `.env`를 `dist\`로 복사해 줌
- 코드를 고친 뒤에는 `build.bat`을 다시 실행해야 exe에 반영됨. exe가 켜져 있으면 먼저 닫을 것
- `build.bat`은 `scripts\` 안에 있지만 저장소 맨 위로 이동해서 빌드함 (진입점은 맨 위 `app.py`)
- 화면 파일(`ui/web/`)은 `--add-data`로, pywebview는 `--collect-all webview`로 같이 묶음.
  웹 화면은 윈도우에 기본으로 깔린 Edge WebView2로 그려짐
- 예전 화면용 `tkinterdnd2`·`customtkinter`도 아직 같이 묶음 (`--ctk`로 띄울 수 있게)
- 백신이 서명 없는 exe를 의심할 수 있음 (직접 만든 파일이면 허용)

```

   ↓
pick_model() → 평소엔 mini, 갱신 작업 중이면 상위 모델
   ↓
모델에게 (대화 기록 + 도구 목록) 전송  ← stream=True: 답 글자가 생기는 대로 말풍선에 바로 표시
   ↓
모델: "update_page_section 을 이 인자로 불러줘"  (tool_calls)
   ↓
run_turn()이 도구 실행 → 결과를 role="tool" 메시지로 다시 전달
   ↓  (도구가 더 필요하면 반복, 최대 15번)
모델: 도구 호출 없이 최종 답변
```

## 도구 추가하는 법

`tools/` 안의 알맞은 모듈(`life.py`, `github.py`, `notion/tools.py`)에 함수를 만들고 `tools/__init__.py`의 `ALL_TOOLS`
(Notion이면 `notion/tools.py`의 `NOTION_TOOLS`)에 넣으면 끝.
docstring이 그대로 모델에게 가는 설명서라서 **언제 쓰는 도구인지** 분명히 적을 것.
인자 타입은 `str`, `int`, `float`, `bool` 지원.

```python
@tool
def roll_dice(sides: int = 6) -> str:
    """주사위를 굴립니다. 사용자가 무작위 선택을 원할 때 쓰세요.

    Args:
        sides: 주사위 면 수.
    """
    import random
    return str(random.randint(1, sides))
```

비서 성격·규칙은 `core/agent.py`의 `SYSTEM_PROMPT`.
